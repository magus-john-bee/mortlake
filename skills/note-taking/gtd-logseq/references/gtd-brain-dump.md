# Initial Brain Dump

**Capture everything in your head in one session.**

---

## What Is a Brain Dump?

A brain dump is a one-time mass capture of everything currently on your mind — every commitment, every open loop, every vague worry, every project you're already doing. The goal is to get it all out of your head and into the inbox so your mind can stop holding it.

David Allen calls this "emptying your head." It usually takes 30–90 minutes the first time.

---

## When to Do It

- When setting up GTD for the first time
- When you've been keeping everything in your head and feel overloaded
- When the weekly review isn't enough and the inbox has overflowed

---

## Before You Start

1. Open [[GTD Inbox]]
2. Set a timer for 30 minutes
3. Put your pen down and start writing

---

## What to Capture

Capture everything without judging, organizing, or deciding. Some prompts to get started:

- **Commitments I've made** — work tasks, personal tasks, favors promised
- **Things I'm worried about** — vague anxieties, unfinished situations
- **Projects I'm working on** — anything I've started but not finished
- **Things I should be doing** — gaps, responsibilities, expectations
- **Ideas and possibilities** — things I might want to do someday
- **People I need to contact** — calls, emails, follow-ups
- **Places things are stuck** — anything waiting on someone else
- **Things to remember** — birthdays, anniversaries, anniversaries of things I want to remember
- **Decisions I've made but not recorded** — choices that need to be written down
- **Old todos I've been carrying** — things I've been meaning to do for a while

---

## How to Write It

Append to [[GTD Inbox]] like this:

```
YYYY-MM-DD HH:mm — [Whatever is on your mind]
```

Don't organize. Don't categorize. Don't decide if it's "good enough." Just write it.

Example:
```
2026-04-21 14:00 — I never followed up on the recruiter from last month
2026-04-21 14:00 — I need to fix the garage door
2026-04-21 14:00 — The kitchen is a mess and it's bothering me
2026-04-21 14:00 — I've been meaning to learn Rust for months
2026-04-21 14:00 — Should I call my sister more often?
2026-04-21 14:00 — The API redesign project is stalled
```

---

## After the Brain Dump

Once everything is in the inbox, **stop**. Don't process yet.

1. Look at what you've captured
2. Take a breath
3. Schedule a processing session — or do it now if you have 30–60 minutes

For the processing session, I can generate a **processing plan**: a file listing every inbox item with a suggested surface and action for each. You review it, adjust as needed, then we apply.

---

## Processing: The 2-Minute Rule

For each inbox item, ask:

1. **Can I do this in under 2 minutes?** → Do it now.
2. **Is it a project (needs more than one step)?** → Create a project page, add a next action to [[Next Actions]].
3. **Am I waiting on someone else?** → Add to [[Waiting For]].
4. **Is it a someday/maybe?** → Add to [[Someday/Maybe]].
5. **Is it reference material?** → File to [[Reference]].
6. **Is it not actionable?** → Delete it.

---

## Processing: Project Identification

Some brain dump items will clearly be projects. Others will be vague. The test:

- **"Finish the API redesign"** → project (many steps)
- **"Send Jane an email"** → next action (one step)

If it takes more than one physical action to complete, it's a project. Create the project page using `template:: project-planning`, then define the first next action and add it to [[Next Actions]].

---

## Tips

- Don't worry about getting it perfect — brain dumps are messy
- If you get stuck, just write "I'm not sure what this means yet" — capture it and move on
- You'll be surprised how much is in your head. That's the point.
- After the first brain dump, you should rarely need another one — just capture as things come up
